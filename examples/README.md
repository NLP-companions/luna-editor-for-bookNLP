# Example book

`EXAMPLE FOLLWOING/` is a short story ready to open in Luna without running BookNLP yourself.

It holds the text (`.txt`) and the files [BookNLP](https://github.com/booknlp/booknlp) wrote for it (`.tokens`, `.entities`,
`.quotes`, `.supersense`, `.book`), unchanged. Luna never changes them: your corrections go to a working copy.

To try it, start Luna, open **Settings → Folders with BookNLP output → Add a folder…** and choose this `examples` folder. The book is listed
with its text already found; choose "Start editing".
